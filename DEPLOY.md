# 🚀 Quick Deploy to Netlify

## Method 1: Drag & Drop (Easiest - 30 seconds)

1. Go to: https://app.netlify.com/drop
2. Download this folder to your computer
3. Drag the `union-glen-website` folder onto the Netlify page
4. Done! Copy the live URL

## Method 2: CLI Deploy (For updates)

```bash
# Install Netlify CLI once
npm install -g netlify-cli

# Login (one time)
netlify login

# Deploy this folder
netlify deploy --prod --dir=/home/node/.openclaw/cmlxjkrzq000004l4s2pxxayg/.openclaw/workspace/union-glen-website
```

## After Deploy

1. Go to your Netlify dashboard
2. Click on your new site
3. Go to "Domain settings" to add your custom domain
4. Go to "Forms" to see registration submissions
